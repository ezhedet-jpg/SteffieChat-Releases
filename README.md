# SteffieChat Releases

Публичный канал проверенных обновлений **Steffie Secure**.

Этот репозиторий не содержит исходный код приложения. Здесь публикуются только:
- APK, подписанные постоянным ключом владельца;
- `update.stmanifest`, подписанный отдельным offline-ключом обновлений;
- краткие примечания к версиям.

Приложение принимает обновление только после проверки:
1. ECDSA-подписи `update.stmanifest`;
2. package name `com.freeman.steffiechat.secure`;
3. versionCode / minSdk / размера APK;
4. SHA-256 APK;
5. постоянного сертификата подписи владельца.

Закрытые ключи (`.p12`) и пароли в этот репозиторий не загружаются.

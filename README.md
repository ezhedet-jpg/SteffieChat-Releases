# Venice Manga Translator — Android
An independent Android screen-overlay translator for reading English-language comics in standard Chrome, powered by OCR on the phone and Venice AI text translation.

This project lives exclusively in the **manga-translator/venice-android** branch. It does not change the Steffie source or release branch.

## Install
After the GitHub Actions job succeeds, download the debug APK from `release-apk/VeniceMangaTranslator-v0.3-debug.apk` in this branch. Android may request permission to install from your browser. The APK is **debug-signed**, so keep the same build/signing key for updates.

## First run
1. Open the app and enter your own Venice API key in the app settings. Do not put it into the repository.
2. Select a Venice model (default: `qwen3-235b-a22b-instruct-2507`) and a modest request limit.
3. Grant overlay/notification/screen-capture permission, then view a legally accessible Toomics page in Chrome.
4. A floating control panel appears over Chrome: tap **▶ Перевести** for immediate translation, **Авто: ВКЛ/ВЫКЛ** to control background translation, **A− / A+** to adjust Russian caption size without extra Venice requests, and **■** to stop. Drag the panel by its header.

## Privacy and limitations
- Local ML Kit OCR runs on the device; only recognized text and minimal previous context are sent to Venice, with your key.
- The screen-capture permission can see other visible apps, so pause it before opening private information.
- This prototype places compact white Russian captions over speech rather than inpainting artwork. The new collision-aware layout skips a caption if it cannot be placed without overlap. Font size defaults to 10 sp and can be set to 7–16 sp. Automatic OCR now checks lightweight frame samples before capturing again, substantially reducing blinking on an unchanged page. It is a prototype, not guaranteed to work on every protected page, orientation, or Android version.
- The APK is generated by CI, not signed for production distribution. For stable upgradable releases, use a protected signing key in GitHub Actions.
- GitHub Actions builds directly from the checked-in `app/` sources. Older `source.b64` archives are retained for history only and are not used by CI.
